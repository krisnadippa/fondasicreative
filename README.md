# fondasicreative

FONDASI CREATIVE SPACE — Official Web App

Interactive animated landing page with OpenPeeps Crowd Canvas, Barriecito typography, and Instagram integration.

## Tech Stack
- [Next.js](https://nextjs.org) (App Router, Turbopack)
- [GSAP](https://gsap.com) (Timeline animations & Canvas renderer)
- [Tailwind CSS v4](https://tailwindcss.com)
- Google Fonts (`Barriecito`, `Geist`)

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
